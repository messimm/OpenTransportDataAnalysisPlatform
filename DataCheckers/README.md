# DataCheckers

Модули `DataCheckers` выполняют лёгкую валидацию и фильтрацию данных перед анализом.

| Файл | Класс | Назначение |
| --- | --- | --- |
| `BasicChecker.py` | `BasicChecker` | Базовая реализация проверки без фильтрации. |
| `MobileOperatorsChecker.py` | `MobileOperatorChecker` | Проверки консистентности агрегатов мобильных операторов. |
| `DataMosChecker.py` | `DataMosGeoChecker` | Проверка координат объектов `data.mos.ru` в ожидаемых границах Москвы. |
| `DataFrameFilterChecker.py` | `DataFrameColumnFilterChecker` | Универсальная фильтрация по непустым полям, допустимым значениям и числовым диапазонам. |

`DataFrameColumnFilterChecker` используется в конфигурациях задач обеспеченности районов: он оставляет объекты с заполненным районом и валидными координатами, а также районы с положительной численностью населения.
